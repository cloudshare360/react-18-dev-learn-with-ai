# React 18 Dev: Learn with AI
## Complete Learning Path from Zero to Job-Ready

This repository contains a comprehensive curriculum designed to take complete beginners to mid-level, job-ready React developers using React 18 and modern development practices.

## 📋 Repository Structure

```
├── requirements.md           # Original project requirements
├── curriculum/              # Complete learning curriculum
│   ├── 01-overview-map.md   # Hierarchical roadmap
│   ├── 02-learning-plan.md  # Detailed curriculum
│   └── 03-timeline.md       # Week-by-week schedule
├── interview-prep/          # Interview preparation materials
│   ├── questions.md         # FAQ and coding challenges
│   ├── behavioral.md        # Behavioral questions
│   └── star-templates.md    # STAR answer frameworks
├── on-the-job/             # Professional development guides
│   ├── codebase-reading.md  # How to read codebases
│   ├── requirements.md      # Clarifying requirements
│   └── workflows.md         # Professional workflows
└── resources/              # Supporting materials
    ├── checklists.md       # Shipping and review checklists
    ├── memory-aids.md      # Recall techniques
    └── anti-patterns.md    # Common pitfalls to avoid
```

## 🎯 Learning Objectives

Transform from complete beginner to job-ready React developer through:
- **Theory**: Deep understanding of React 18 concepts
- **Practice**: Hands-on exercises and mini-projects
- **Reinforcement**: Spaced repetition and review systems
- **Interview Prep**: Technical and behavioral question practice
- **Professional Skills**: Real-world development workflows

## 🚀 Getting Started

1. Start with [`curriculum/01-overview-map.md`](curriculum/01-overview-map.md) for the learning roadmap
2. Follow the detailed plan in [`curriculum/02-learning-plan.md`](curriculum/02-learning-plan.md)
3. Use [`curriculum/03-timeline.md`](curriculum/03-timeline.md) for scheduling
4. Prepare for interviews with materials in [`interview-prep/`](interview-prep/)
5. Develop professional skills using guides in [`on-the-job/`](on-the-job/)

## ⏱️ Time Investment

- **Total Duration**: ~16-20 weeks (part-time)
- **Weekly Commitment**: 15-20 hours
- **Total Hours**: ~300-400 hours

## 🛠️ Technology Stack

- **Core**: React 18, JavaScript/TypeScript
- **Build Tools**: Vite, Node.js/NPM
- **Styling**: CSS Modules, Tailwind CSS
- **State Management**: Context API, Redux Toolkit, TanStack Query
- **Testing**: Jest, React Testing Library
- **Deployment**: Netlify, Vercel
