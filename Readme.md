Role: Act as an expert React developer (React 18, modern ecosystem).

Goal: Take a beginner from zero to mid-level, job-ready React developer.

Requirements
	•	Base everything on React 18 and current, mainstream practices in modern React JS development.
	•	Provide a detailed, step-by-step learning plan organized hierarchically (from fundamentals → intermediate → advanced → job-ready).
	•	For each topic:
	•	Explain the concept clearly.
	•	Provide hands-on exercises.
	•	Include reinforcement activities (spaced repetition ideas, flashcards, review checklists).
	•	Add mini-projects at each level to consolidate learning.
	•	Include a timeline with estimated total hours and per-module hour ranges.
	•	Include a section of commonly asked interview questions (conceptual + practical) aligned to each module.
	•	Consider multiple dimensions of success:
	•	Learning (theory), Hands-On Doing, Executing tasks, Interview preparation, Remembering (mnemonics/spaced repetition), Organizing thoughts/answers, On-the-job task understanding, Asking the right questions.
	•	Produce clear guidance that helps a newcomer become mid-level and job-ready.

Deliverables
	1.	Overview Map: A one-page hierarchical roadmap of topics (bullet tree).
	2.	Requirements Recap: The above requirements summarized in 6–8 bullets.
	3.	Learning Plan: Multi-level curriculum with:
	•	Learning objectives
	•	Concepts explained simply
	•	Hands-on tasks
	•	Reinforcement (quizzes, flashcards prompts, review checklists)
	•	Mini-projects per level (with acceptance criteria)
	•	Estimated hours per item and cumulative totals
	4.	Timeline: Week-by-week (or day-by-day) schedule with target hours and outcomes.
	5.	Interview Prep Pack:
	•	Frequently asked questions (with succinct answers)
	•	Whiteboard/code challenges
	•	Behavioral question bank tailored to React roles
	•	STAR answer templates
	6.	On-the-Job Playbook:
	•	How to read a codebase
	•	How to clarify requirements and ask the right questions
	•	Task breakdown templates
	•	PR etiquette, debugging workflow, and testing checklist
	7.	Checklists & Memory Aids:
	•	“Before you ship” checklist
	•	Topic recall ladders & spaced-repetition schedule
	•	Common pitfalls & anti-patterns

	•	Core: JSX, Components, Props, State, Events

	•	State Management: Context vs. Redux Toolkit, query/caching tools (React Query/TanStack Query)

	•	Styling: CSS Modules, CSS-in-JS, Tailwind (optional), design systems

	•	Tooling: Node/NPM, Vite or CRA alternatives, ESLint, Prettier, TypeScript (intro then applied)
	•	Build & Deploy: Env configs, .env, basic CI, deploying to Netlify/Vercel
	•	Accessibility & UX: a11y basics, ARIA, keyboard nav
	•	Real-World Patterns: Folder structure, API layers, error boundaries, feature flags

Output Format
	•	Use Markdown with:
	•	Collapsible sections for each module (if possible)

	•	Each module must end with:
	•	Hands-On Tasks
	•	Reinforcement Plan

	•	Interview Questions

Constraints

	•	Keep explanations clear, concise, and practical.

	•	Show hour estimates and total hours at the end.
